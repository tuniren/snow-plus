# Snow Plus

把雪球变成一个安静的、接近 GitHub 的阅读工作区。原生 Chrome 扩展，使用 Manifest V3，无运行时依赖、无需构建。

## 安装到 Chrome

1. 打开 `chrome://extensions/`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目目录（包含 `manifest.json` 的目录）。
3. 打开或刷新 <https://xueqiu.com/>。`www.xueqiu.com` 同样支持。
4. 将 Snow Plus 固定到工具栏，可以随时调整或关闭专注模式。

默认启用 GitHub 风格的浅色导航、仓库标题、Issues 风格讨论列表和低饱和度配色。首页以资讯和讨论为主体，左侧为仓库式栏目导航与预设搜索，右侧为 README、阅读说明和快捷键；隐藏原站左右侧栏、发帖框，默认收起股价、自选列表、首页宣传横幅及帖子中的图片和视频。保留原站的文章、评论、搜索和登录逻辑，不复制或代理雪球数据。

「隐藏图片和视频」默认开启，同时隐藏讨论预览缩略图、转发配图和相册预览及其占位。关闭该选项会恢复显示，新加载的讨论同样遵循设置。

## 操作

| 入口 | 功能 |
| --- | --- |
| 扩展图标 | 启用/关闭专注模式，调整所有阅读偏好 |
| 页面右上角齿轮 | 隐藏媒体、收起行情、紧凑布局、标签页伪装和恢复原样 |
| Discussions / News / Following | 切换原站热门讨论、资讯和关注栏目；左右侧栏不会遮挡讨论列表 |
| 左侧 Saved searches | 打开行业观察、公司研究、每周复盘的预设搜索 |
| 顶部「切换公司」或左侧 Companies | 按公司名称或股票代码搜索；可直接打开比亚迪 A 股（SZ002594）和港股（01211），查看公司讨论、资讯及公告 |
| 原站导航 | 临时展开雪球导航，使用原站登录及账户入口 |
| `/` | 聚焦顶部的雪球搜索框；在输入框内正常输入不受影响 |
| `Esc` | 关闭页面内设置面板 |
| `Alt + Shift + X` | 全局切换扩展的专注模式，已打开的雪球页面同步更新 |

Chrome 如未分配快捷键，可到 `chrome://extensions/shortcuts` 配置。关闭专注模式会恢复原站样式、标签页标题和 favicon；页面内设置关闭后，可通过扩展弹窗或快捷键重新启用。设置通过 `chrome.storage.sync` 保存，多个雪球标签页会同步更新。

## 本地预览与开发

安装扩展不需要 Node.js。开发工具需要 Node.js 20+。

```sh
npm install
npm run preview
```

打开 <http://127.0.0.1:4173>。预览页面采用雪球首页的组件类名和本地示例内容，可检查布局、切换设置、加载新行、点赞和打开示例评论；底部标注「本地预览」。预览设置只存在当前本地站点，不影响扩展设置。

```sh
npm run check
npx playwright install chromium
npm test
npm run package
```

浏览器测试将真实扩展加载到 Chromium，通过拦截雪球首页请求提供确定性的页面样本，覆盖登录后三栏首页和未登录首页、资讯与讨论切换、刷新滚动后的文章遮挡检查、跨页设置同步、样式恢复、动态内容、SPA 导航、标签页恢复、键盘操作、窄窗口及域名隔离。无需登录雪球。

也可用环境变量 `SNOW_PLUS_BROWSER_PATH` 指向支持命令行加载扩展的本机 Chromium / Edge 可执行文件，跳过测试浏览器下载。

打包输出为 `artifacts/snow-plus-0.1.0.zip`，只包含运行所需文件及说明文档，不含预览、测试或 `node_modules`。解压后同样可通过「加载已解压的扩展程序」安装。

## 项目结构

```text
manifest.json          Chrome Manifest V3，唯一 API 权限是 storage
src/content.css        GitHub 风格与雪球组件选择器
src/content.js         页面导航、设置面板、标签页标题和图标
src/shared.js          默认值、设置存储和变更订阅
src/background.js      快捷键切换
src/popup.*            扩展弹窗
icons/                 扩展 PNG 图标
preview.html, demo/    本地预览样本
scripts/               校验、预览服务、ZIP 打包
tests/                 Chromium 扩展集成测试
```

## 适配范围

桌面端首页及公司页（`/S/股票代码`）采用三栏阅读布局，窗口变窄时依次收起右侧和左侧面板，优先保留讨论正文。公司页可切换讨论、资讯与公告，默认隐藏报价、走势图及交易操作。公司搜索使用原站搜索接口，名称搜索不可用时可按代码打开，或搜索相关讨论。搜索、文章、个人页会应用全局配色与顶部导航，复杂页面的内部布局保留原站实现。雪球的动态类名使用稳定的组件名前缀匹配，避免依赖构建哈希。新增内容直接继承 CSS，无需搬运或重建原站节点。关闭专注模式会移除自定义侧栏及布局标记，恢复原站栏目。

行情文字和帖子内容保留原值，涨跌的正负号不会被改写。外观调整不会改变网址。站点组件结构更新后，可能需要在 `src/content.css` 中补充选择器。

扩展仅匹配 `https://xueqiu.com/*` 和 `https://www.xueqiu.com/*`，不申请浏览历史、Cookie、网络拦截等权限，不接入统计或外部服务。
